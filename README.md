# Student Records Data Processor

## Project Description

The Student Records Data Processor is a JavaScript project that manages and analyzes student information. It processes student records, calculates grades, identifies top students, groups students by course, and generates a summary report.

## Features

- Calculate student average grades
- Find top-performing students
- Group students by course
- Count enrolled students
- Search for a student
- Calculate course averages
- Generate a student summary report

## Technologies Used

- JavaScript
- JSON
- Node.js

## Installation/Usage

1. Clone or download the repository.
2. Make sure Node.js is installed.
3. Open the project folder in the terminal.
4. Run the application using:

```bash
node app.js
